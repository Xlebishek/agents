## 🎯 Обзор проекта

**Student Risk Analytics Dashboard** — это аналитическое решение на базе Power BI для выявления студентов, находящихся в зоне риска отчисления.

### 🔑 Ключевые задачи:
- 🔴 Ранжировать студентов по уровню академического риска
- 📊 Анализировать проблемные предметы и преподавателей  
- 📈 Отслеживать динамику успеваемости по семестрам
- 🏷️ Автоматически маркировать студентов с критическими показателями

---

## ✨ Основные возможности

| Функция | Описание |
|---------|----------|
| 🔴 **Индекс риска студента** | Взвешенная оценка: посещаемость + просрочки + пересдачи + оценки |
| 🌡️ **Тепловая карта** | Визуализация рисков по предметам для каждого студента |
| 📈 **Тренд успеваемости** | Динамика среднего балла по семестрам в виде линейного графика |
| 🏷️ **Метки статуса** | Автоматические бейджи: низкая посещаемость, пересдачи, зона риска |
| 🎯 **ТОП рисков** | Список студентов с наибольшим индексом риска |
| 📉 **Анализ по предметам** | Выявление предметов с наибольшей долей рискующих студентов |
| 🔄 **Интерактивные фильтры** | Срезы по курсу, полу, возрасту |

## 📊 Метрики и индексы

### 1. Индекс риска студента (взвешенный)

Индекс риска рассчитывается как сумма взвешенных признаков академического неблагополучия:

| Признак | Условие | Вес |
|---------|---------|-----|
| Низкая посещаемость | `attendance_percentage < 70%` | **1** |
| Систематические просрочки | `assignments_on_time_percent < 70%` | **1** |
| Наличие пересдач | `retakes_count_semester > 0` | **2** |
| Плохая оценка | `exam_grade IN {"F","E","D"}` | **3** |

## 2. Индекс риска по предмету

Аналогичный индекс, но вычисляется в контексте конкретного предмета для каждого студента. Используется в тепловой карте.

## 3. Числовое преобразование оценок

Для расчёта среднего балла и построения трендов используется следующая шкала соответствия:

| Буквенная оценка | Числовое значение |
|-----------------|------------------|
| A               | 5                |
| B               | 4                |
| C               | 3                |
| D               | 2                |
| E               | 1                |
| F               | 0                |

## 4. Средний балл за семестр

## 📈 Ключевые показатели (KPI)

| Метрика | Формула | Описание |
|---------|---------|----------|
| Total Students | `DISTINCTCOUNT('Sheet1'[student_id])` | Общее количество студентов |
| Students at Risk | `SUMX(VALUES('Sheet1'[student_id]), IF([Risk Index Weighted] >= 3, 1, 0))` | Количество студентов в зоне риска |
| Avg Risk Index | `AVERAGEX(VALUES('Sheet1'[student_id]), [Risk Index Weighted])` | Средний индекс риска по всем студентам |
| Risk % | `DIVIDE([Students at Risk], [Total Students], 0)` | Доля студентов в зоне риска |

## 🎨 Шкала риска

| Диапазон | Уровень | Цвет | Описание | Рекомендации |
|----------|---------|------|----------|-------------|
| 0 | Стабилен | 🟢 | Отличная успеваемость, нет проблем | Мониторинг, без вмешательства |
| 1–2 | Зона внимания | 🟡 | Есть незначительные проблемы | Рекомендательная беседа |
| 3–4 | Высокий риск | 🟠 | Серьёзные проблемы с успеваемостью | Обязательная встреча с куратором |
| 5+ | Критический риск | 🔴 | Высокая вероятность отчисления | Немедленное вмешательство |

## 📈 Тренд успеваемости

**Тип визуала:** Линейный график (Line chart)

### Настройка осей и легенды

| Ось | Поле | Примечание |
|-----|------|------------|
| **X** | `semester` | Отсортированный по возрастанию |
| **Y** | `Avg Grade Semester` | Средний балл за семестр |
| **Легенда** | `student_id` (или `subject`) | Для анализа по студентам или предметам |

### Возможности визуализации

- 🔍 **Отслеживание динамики** среднего балла конкретного студента во времени
- ⚖️ **Сравнение трендов** разных студентов на одном графике
- 📉 **Выявление студентов** со снижающейся успеваемостью (нисходящий тренд)
- 📊 **Анализ сезонности**: оценка влияния конкретных семестров на успеваемость
- 🎯 **Прогнозирование**: визуальная оценка траектории и раннее выявление рисков
